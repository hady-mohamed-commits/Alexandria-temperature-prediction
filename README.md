🌡️ Alexandria Temperature Prediction

📌 Project Overview

This project focuses on predicting temperature in Alexandria, Egypt, using Machine Learning techniques. It aims to analyze weather data and build a predictive model that estimates temperature based on the available features.

🎯 Project Objectives

* Analyze and explore historical weather data.
* Perform data cleaning and preprocessing.
* Identify patterns and relationships in weather features.
* Train and evaluate Machine Learning models.
* Predict temperature using the trained model.

🛠️ Technologies & Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook / Google Colab

🔍 Project Workflow

1. Data Collection
2. Exploratory Data Analysis (EDA)
3. Data Cleaning and Preprocessing
4. Outlier Detection and Handling
5. Feature Engineering and Selection
6. Train-Test Split
7. Model Training
8. Model Evaluation
9. Temperature Prediction

📊 Model Evaluation

The models are evaluated using appropriate regression metrics, such as:

* MAE (Mean Absolute Error)
* MSE (Mean Squared Error)
* RMSE (Root Mean Squared Error)
* R² Score

These metrics help measure prediction errors and evaluate how well the model performs.
